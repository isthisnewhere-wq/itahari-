## Publishing standards

Each new article needs a distinct reader question, enough useful detail, one primary core topic, natural links, and only verified café claims. Do not create pages merely to consume keyword variants. Confirm recipes / serving details before writing café-specific claims. These are candidate topics rather than measured keyword demand.
